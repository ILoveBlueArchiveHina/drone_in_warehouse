# ROS 2 Drone in Warehouse

This ROS 2 package is part of an indoor UAV warehouse inspection project.
It provides a simulated environment built in Gazebo, enabling end-to-end testing and validation of the entire software stack. Within this environment, we can evaluate and integrate key functionalities including SLAM, navigation, and other autonomy modules before deploying them on the real UAV.

The package is designed to:
- Build a realistic warehouse simulation world.
- Support UAV operation and mission testing in a safe, controlled environment.
- Serve as a development and verification platform for SLAM, localization, and navigation pipelines.

##  Prerequisites

- ROS 2 Jazzy most be installed
- Python 3
- Created a ROS 2 workspace ('ros2_ws')
